# 三国 · 战阵 — 网页卡牌对战 Demo

纯前端、零依赖的三国题材卡牌对战 Demo：3×3 战场、内政产费、主将 12 血，人机对战。

**在线试玩：** https://emp-0.github.io/sanguo-card-demo/

## 玩法

- 两套 20 张草稿牌组：**汉军 · 匡扶汉室** 与 **黄巾 · 苍天已死**
- 3×3 战场（先锋 / 中军 / 后卫 × 3 列），攻击同列最前单位，空列则攻城
- 内政区横置产 1 点兵权；支持多兵权（如 `步/骑` 二选一产费）
- 通用卡牌 DSL：`[条件:N阵营][触发器][效果ID, 参数...]`
- 关键词：敏捷、贯穿、守军、抵抗、相邻/整排增益、鼓舞、行攻城、光环、免攻

## 本地运行

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
```

```text

js/ui.js        渲染与交互
```
